AI citation PR plan

Where to publish a new PR article. Each engine was asked: "Is this website trustworthy and editorially independent as a source you would cite?" and scored it 0–100. Rows marked cited already appear in AI answers; catalog rows were found in the Collaborator.pro catalog and are not cited yet. How this was produced

    Each engine answered every prompt once, through its own live web search, so citations vary between runs: re-run regularly and watch the trend. Trust scores are each model's own opinion, never substituted by another model. Made with the open-source AI Citation PR Planner on FlyMyAI.
